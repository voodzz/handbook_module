# Описание справочников

**ФИО:** Войтукевич Руслан Юрьевич
**Год:** 2026
**Курс:** 3
**Группа:** 2

## 1. Названия справочников
1. **Футбольные клубы** (`football_clubs`)
2. **Футболисты** (`football_players`)

## 2. Перечни колонок

### Футбольные клубы
* `club_id` (Целое число) — уникальный код клуба.
* `club_name` (Текст) — название клуба.
* `creation_date` (Дата) — дата основания клуба.
* `stadium_name` (Текс) — домашний стадион клуба.
* `uefa_rating` (С фиксированной запятой) — [УЕФА рейтинг](https://ru.uefa.com/nationalassociations/uefarankings/club/?year=2026) клуба.

### Футболисты
* `player_id` (Целое число) — уникальный код игрока.
* `first_name` (Текст) — имя спортсмена.
* `last_name` (Текст) — фамилия спортсмена.
* `birth_date` (Дата) — дата рождения спортсмена.
* `club_name` (**Ссылка на справочник клубов**) — название клуба, за который играет.
* `height` (С фиксированной запятой) — рост спортсмена в метрах.
* `market_value` (Целое число) — стоимость игрока в евро по оценке [Transfermarkt](https://www.transfermarkt.com/navigation/marktwerte).
